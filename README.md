# Eventernote Power List

Userscript enhancements for Eventernote event list pages.

## Features

- Compact list mode for dense event browsing.
- Keyword highlight and mute rules for event title, venue, and actors.
- Popularity badges based on Eventernote note/attendance count.

## Install

Install `src/eventernote-power-list.user.js` in Tampermonkey, Violentmonkey, or another userscript manager.

## Supported Pages

- `https://www.eventernote.com/events/*`
- `https://www.eventernote.com/events`

## Settings

Open any Eventernote event list page and use the `Power List` panel in the lower-right corner.
Settings are stored locally in your browser with `localStorage`.

## Development

```sh
npm run check
```
