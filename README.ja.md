# Eventernote EX

[简体中文](README.md) · [English](README.en.md) · **日本語**

[Eventernote](https://www.eventernote.com/) でのイベント探し、参加予定の整理、参加記録の振り返りを使いやすくするユーザースクリプトです。

[インストール](https://greasyfork.org/ja/scripts/583130-eventernote-ex) · [ソース](src/eventernote-power-list.user.js) · [不具合報告](https://github.com/wr786/eventernote-ex/issues)

## はじめに

1. ブラウザーに Tampermonkey、Violentmonkey などのユーザースクリプトマネージャーをインストールします。
2. [GreasyFork のページ](https://greasyfork.org/ja/scripts/583130-eventernote-ex)から **Eventernote EX** をインストールします。
3. Eventernote にログインし、[自分のマイページ](https://www.eventernote.com/users)を一度開きます。お気に入りの声優・アーティストとサイト上の参加回数がキャッシュされます。

イベント検索の「按关注推荐」、マイページの回数表示切り替え、「我的现场」が利用できます。お気に入りや回数が変わったら、マイページを開き直してキャッシュを更新してください。

> 独立した [Eventernote 参加回数表示](https://greasyfork.org/ja/scripts/369760) も使用している場合は、回数の二重表示を避けるため無効にしてください。

## イベント探し・一覧表示

| 機能 | 動作と対象 |
| --- | --- |
| 複数ページのおすすめ | イベント検索・月別一覧の「按关注推荐」で、お気に入り出演者の参加回数の合計に基づいて並べ替えます。最初は最大 10 ページをまとめ、「加载更多推荐」で毎回最大 10 ページずつ追加します。重複除去、進捗表示、再試行、元の並び順への復帰に対応します。 |
| お気に入り出演者バッジ | マイページの回数バッジと共通の 7 段階のメタリック配色を使用します。出演者バッジには名前だけを表示し、回数やランク名は追加しません。 |
| イベントの人気表示 | サイトの参加者数を 10 / 50 / 100 人の段階で強調します。個人の参加回数とは別の表示です。 |
| 会場の地図 | 会場名の横にある `map` から Google Maps で検索できます。 |
| 同日のイベント検索 | 日付の横にある `all` から、その日のほかのイベントを探せます。 |
| コンパクト表示 | 対応するイベント一覧の行間を詰め、サムネイルを非表示にします。 |

## マイページ

### 参加回数の表示モード

声優・アーティスト一覧の横で切り替えます。選択はブラウザー内に保存されます。

- **徽章模式 — バッジモード**：文字サイズを統一し、細い区切り線と右揃えのメタリックな回数バッジを表示します。表示は `126回` のみです。長い名前は 1 行で省略され、マウスを重ねると全文を確認できます。
- **紧凑徽章 — コンパクトバッジ**：名前と回数を一つの金属グラデーションのバッジにまとめ、横並びで配置します。バッジ単位で折り返し、文字サイズを統一します。長い名前は 1 行で省略し、ホバーで全文を確認できます。集計範囲と並び順の切り替えにも対応します。
- **原版模式— オリジナルモード**：サイトの文字サイズの段階と色を保ち、回数を `[126回]` と表示します。長い名前と回数は列幅に合わせて縮小し、1 行に収めます。

声優・アーティストのランキングページでも、名前の横に `[n回]` を表示します。

自分のマイページでは、**集計範囲**を全登録（将来の予定を含む）と今日までに切り替えられます。「今日まで」は全履歴を読み込み、日本の日付で未来のイベントを除外し、イベントの重複を取り除いて回数・金属ランク・降順を更新します。両方の表示モードに対応し、今日のイベントは終演時刻にかかわらず含みます。全登録に戻すと元の値と順序に復元され、読み込み失敗時は直前の集計を保持します。履歴は現在のページ内で「我的现场」と共有します。

### 7 段階のメタリック配色

出演者バッジとマイページの回数バッジで共通の基準を使用します。以下のランク名は配色の説明用で、バッジの文字には表示しません。

| サイト上の参加回数 | ランク |
| ---: | --- |
| 0–9 | 黒鉄 |
| 10–29 | ブロンズ |
| 30–49 | シルバー |
| 50–99 | ゴールド |
| 100–149 | ブラックゴールド |
| 150–199 | ブラックダイヤモンド |
| 200+ | ルビー |

### 我的现场 — 参加予定と記録

自分のマイページに表示され、**初期状態では折りたたまれています**。見出しをクリックして開閉できます。閉じても、そのページで読み込んだ記録は保持されます。

| 画面 | 内容 |
| --- | --- |
| 参加予定カレンダー | 今日以降の自分の登録予定を月別に表示します。日付を選ぶと、その日のイベント、時刻、会場を確認できます。 |
| 年間の振り返り | 年を選び、今日までの登録イベント数、イベントのある日数、会場数、月別分布、出演者・会場の上位を確認できます。将来の予定は別に集計します。 |
| 節目までのカウントダウン | 全記録からお気に入り出演者の過去の出演イベント数を再計算し、次の目標までの残り回数を表示します。将来の予定から、達成候補の日付とイベントも示します。目標は 10 / 20 / 30 / 50 / 100 / 150 / 200 回、その後は 50 回ごとです。 |

**「读取完整参加记录」** を押すと、自分の参加記録を最大 100 ページまで順に読み込みます。進捗表示、元データの総件数確認、イベントの重複除去、再試行に対応します。完了するまではカレンダーにマイページ上の予定だけをプレビュー表示し、不完全な記録から年間集計やカウントダウンは生成しません。

### 参加予定の行程表示

自分のマイページの参加予定欄から開きます。日付と開演時刻順に整理し、日付の絞り込み、会場、開場・終演時刻、イベント間の空き時間や重複を確認できます。元の一覧にも戻せます。

対象は**現在のマイページに掲載されている本人の予定だけ**です。検索結果やお気に入り出演者のおすすめイベントは含みません。全記録を読み込むカレンダーとは対象範囲が異なります。

## データと制限事項

- 設定とお気に入り出演者のキャッシュはブラウザーの `localStorage` に保存します。全参加記録は現在のページのメモリー内だけに保持され、再読み込み後は取得し直す必要があります。ページ追加取得では Eventernote 自身のページにアクセスします。
- 年間集計とカウントダウンは**日本の日付**で過去と未来を分けます。当日のイベントが終了したかどうかは判定しません。サイトへの登録は実際の参加を証明するものではありません。
- マイページの回数は初期状態ではサイト上の値です。「今日まで」とカウントダウンは重複除去後の過去のイベントから再計算した値です。集計方法が異なるため、数が一致しない場合があります。予測は将来の予定にすべて参加する前提であり、達成済みを意味しません。
- 空き時間に**移動時間は含まれません**。時刻未定、日をまたぐイベント、サイト上で未更新の終演時刻は個別に確認してください。
- サイトの構造変更により機能が動かなくなる場合があります。専用のモバイルレイアウトはありません。
